## Overview

This repository extends the WebStudio landing page with CSS styling, typography, color design, and normalized browser styles.

## Tech Stack

- HTML5
- CSS3
- Google Fonts
- Normalize.css
- Git & GitHub

## Implemented Features

- semantic page structure;
- reusable CSS classes;
- typography with Roboto and Raleway;
- styled navigation and contact links;
- hero section styling;
- team and portfolio section styling;
- consistent colors, spacing, and visual hierarchy.

## Learning Outcomes

- connecting external stylesheets;
- CSS selectors and class-based styling;
- typography and font integration;
- colors and spacing;
- browser style normalization;
- separating content from presentation.
